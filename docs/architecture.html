System Architecture

High-level overview of the system design and data flow.

Sensing Layer

Environmental sensors collect real-time data for processing by the microcontroller.

Processing Layer

SAM D21 MCU runs custom firmware to process, filter, and package sensor readings.

Communication Layer

Wi-Fi module transmits data via MQTT to the cloud for storage and analysis.

Application Layer

Node-RED dashboard provides real-time visualization and device management.
